# Impulse Studios Website

A modern, immersive gaming studio website built with HTML, CSS, and JavaScript. The site features a sleek black and blue color theme inspired by contemporary gaming industry design.

## Features

- **Modern Design**: Gradient backgrounds, smooth animations, and interactive elements
- **Responsive Layout**: Fully responsive design that works on desktop, tablet, and mobile devices
- **Dark Theme**: Black and blue color scheme with accent colors for visual appeal
- **Sections**:
  - Hero Section with loading animation
  - Main Banner with statistics
  - Experiences Gallery
  - Services Showcase
  - Contact Form
  - Footer with Links

## Color Palette

- **Primary**: #0f3460 (Dark Blue)
- **Secondary**: #16213e (Darker Blue)
- **Accent**: #00d4ff (Cyan Blue)
- **Accent Purple**: #7c3aed (Purple)
- **Text Light**: #e0e0e0 (Light Gray)
- **Background**: #0a0e27 (Very Dark Blue)

1. Open `index.html` in a web browser
2. Navigate through different sections using the top navigation bar
3. Fill out the contact form to send a message
4. Scroll to see animations and effects

## Customization

### Colors
Edit the CSS variables in `:root` section of `styles.css`:
```css
:root {
    --primary-color: #0f3460;
    --accent-color: #00d4ff;
    /* ... other colors ... */
}
```

### Content
- Edit section titles and descriptions in `index.html`
- Add your own game cards and services
- Update contact information in the footer

### Animations
Modify animation timings and effects in `styles.css` and `script.js`
